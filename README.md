# TDM AMG — bản phát hành Android

Repo này CHỈ chứa APK đã ký chính thức và `version.json` (app đọc để tự cập nhật). Không có mã nguồn, không có dữ liệu bệnh nhân.

- Tải bản mới nhất: mục **Releases** bên phải → tệp `tdm-amg-<phiên bản>.apk`.
- Các bản phát hành được tạo tự động bởi GitHub Actions của repo mã nguồn (riêng tư), ký bằng khóa phát hành.
- Android chỉ cho cài đè bản cập nhật khi APK được ký cùng khóa — APK giả mạo không thể thay thế app đang cài.
